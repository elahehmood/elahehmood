### 🧠 Advanced Data Mining Models for Customer Behavior Analytics
- **Description**: A research project analyzing customer behavior using advanced data mining techniques, including churn prediction, survival analysis, uplift modeling, and sequence modeling.

- **Highlights**: Achieved 85% ROC-AUC for churn prediction and optimized GRU4Rec for sequential recommendations with MRR@5 of 0.72.
